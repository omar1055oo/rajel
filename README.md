# راجل ولا مش راجل

1. الصق `firebaseConfig` في `src/firebase.js`.
2. عدّل الأسماء في `src/accounts.js` (الإيميلات a@rajel.app و b@rajel.app).
3. الصق `firestore.rules` في Firebase وبدّل `UID_A` و`UID_B`.
4. `npm install` ثم `npm run dev` للتجربة، `npm test` للاختبارات، `npm run build` للنشر على Vercel.
